# Roadmap

## 0.2 — control-plane persistence

PostgreSQL repository, migrations runner, transactional jobs, persistent throttling, reset/verification/TOTP, encrypted secrets, hash-chained audit, packages/quotas, API tokens and idempotency.

## 0.3 — hosting primitives

Transactional Nginx/domain/TLS, isolated PHP-FPM, Python/Gunicorn and Node systemd runners, static/React builds, cgroup v2 quotas, MariaDB/PostgreSQL tenant grants, deployment histories.

## 0.4 — customer operations

Full file/archive manager, Monaco IDE, xterm terminal gateway, cron allowlist, Git credentials, logs/metrics, notifications, restic backup/restore with rehearsed disaster recovery.

## 1.0 candidate

Hosted-mail decision, reseller UX, accessibility/e2e suite, clean Ubuntu installer matrix, penetration test, restore drills, performance baselines, signed update channel, complete administrator/customer guides.
